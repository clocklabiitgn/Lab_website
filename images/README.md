# Images folder

Put member photos and any figures here, then reference them in the Google
Sheet as `images/filename.jpg` (relative path — no need for the full web address).

## Guidelines
- **Headshots**: square, at least 300×300px, `.jpg` or `.png`. They'll be
  cropped to a circle automatically — center the face.
- **Research figures**: any reasonable size; they display at ~260px tall,
  cropped to fit, so widescreen images work best.
- Keep filenames simple: lowercase, no spaces — e.g. `shashank-singh.jpg`,
  `pi-photo.jpg`, `research-clock-diagram.png`.

## How to add one
1. In the GitHub repo, open this `images` folder.
2. Click **Add file → Upload files**, drop your photo in, **Commit changes**.
3. In the Google Sheet, put `images/your-file-name.jpg` in the **Photo**
   (Members/Home tab) or **Image** (Research tab) column.

If a Photo cell is left blank, the site shows a neat circle with the
person's initials instead — so the page never looks broken while you're
still collecting photos.
